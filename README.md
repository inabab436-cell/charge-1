# Order Harmony

اريد بناء نظام دقيق جداً 

يفعل شئ بسيط ولكن محكم 

متصل ب شركة الشحن بوسطه



وافكر أيضا إذا أجعله متصل بوشبيفاي لجلب الاوردرات 

ولكن هذا ليس شئ نهائي لأن ليس كل التجار يستخدموا شوبيفاي 

إذن من أين نوفر طريقه سهله لجلب الاوردرات 

المهم نرجع الفكره

  التاجر يعرف الاوردرات اللي فلوسها جت من شركة الشحن واللي لسه مجتش 

وكمان اللي جت هل مظبوطه فعلاً ولا فيها خصومات أو فلوس ناقصه 



الفكره كيف نجعل النظام يعرف بشكل صحيح وينسب المعلومات للأوردر الصحيح 

وفي نفس الوقت لا نجعل الموقع يفعل شئ يستطيع التاجر يفعله يدوي



يجب أن يكون سهل ذكي دقيق
